# Security Policy

## Supported Versions
Currently, only the latest release of Scandisk is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please report any security vulnerabilities via GitHub issues or directly to the project maintainers. 

We take security issues seriously and will respond to reports as quickly as possible. Please provide a detailed description of the issue, including steps to reproduce the vulnerability.

### Response Plan
1. We will acknowledge your report within 48 hours.
2. We will investigate the issue and determine if it is a valid vulnerability.
3. If valid, we will work on a patch and release an updated version.
4. We will publicly disclose the vulnerability only after a patch is available and users have had time to update.
